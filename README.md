# English Pet Care Plan

面向中文母语成年人的低压英语陪学伙伴。用户完成短而可解释的词汇练习，获得服务端确认的学习回执、下一次复习建议和 Momo 的安静回应；离开不会失去关系、学习资格或已有内容。

> 规则版本：v0.3（2026-08-23）
>
> 当前状态：已根据英语学习与陪伴类竞品、公开用户评价完成市场评审并冻结新版 Beta 需求。陪伴状态机领域基线和欢迎/今日页前端基础仍保留为探索性实现，不再是 Beta 的功能门槛；真实会话、数据库、词库、学习计划、积分事务和端到端闭环仍待实现。

## 技术基线

- 小程序前端：Taro + React + TypeScript；H5 仅用于浏览器回归验证。
- 服务端：FastAPI + Python，是学习计划、积分、权益、陪伴记忆与时间的唯一规则权威。
- 数据：PostgreSQL + SQLAlchemy；M1 起引入 Redis 处理缓存、限流与幂等协调。
- 测试：Vitest + Testing Library（前端单元测试）、Pytest（服务端测试）、Playwright（H5 冒烟测试）；微信平台能力以开发者工具/真机补充验证。
- 架构和本地运行说明见 [docs/architecture.md](docs/architecture.md)。多 Agent 协作流程见 [docs/agent-collaboration.md](docs/agent-collaboration.md)。
- 正式需求见 [docs/product-requirements.md](docs/product-requirements.md)，市场评审与来源见 [docs/product-market-review.md](docs/product-market-review.md)，可交互的 Beta 原型见 [docs/prototype/beta-v0.3.html](docs/prototype/beta-v0.3.html)；[docs/prototype/index.html](docs/prototype/index.html) 是历史概念原型。

## 首轮 Beta 的价值与范围

用户每次用约 5–8 分钟完成一组词汇练习，看到可信的纠错和下一次复习建议，并收到一次不打扰学习的 Momo 反馈。首轮招募 20–30 名年满 18 周岁的中文母语用户进行 14 天封闭测试。

- 入组时可选择“日常沟通、旅行、职场基础、先体验”及自评熟悉度；跳过时使用通用起始词包。
- 只上线一个规模受控、可审计且已授权的通用词包。每个词条必须有释义、例句、译文、词性、难度、来源/许可、版本和下架标记。
- 每组为服务端签发的 10 题，由应复习词、少量新词与错词组成；具体配比经过内部预试后配置化。
- 正确率至少 80% 时获得 8 积分，每日最多 3 次。积分、额度、本地日与复习计划均由服务端裁决，重复提交不得重复奖励。
- 结果页必须展示错词、正确答案、简短语境说明、服务端给出的下一次复习建议，以及提交中/已确认/可查询/可重试状态。

阅读、口语、语音评分、犬类、多宠物、社交、排行榜、广告、真实收款、长视频和动态视频均不属于首轮 Beta。

## 陪伴原则

- 每个账户可领养并命名一只默认猫咪 Momo；Momo 是学习的同伴和记忆见证者，不是需要按时维护的任务。
- 喂食、补水、整理和打招呼是任选、免费的表达互动；它们不改变学习资格、积分、成长资格、内容可见性或购买权益。
- 用户长期离开后直接看到“欢迎回来”与最近共同记忆；无需重逢动作、不得出现倒计时、休养门槛、扣分、受伤或关系降级。
- 服务端确认学习后可返回一条基于事实的温和反馈和可选记忆。每天最多一次明显完成动画，其余为轻量更新，避免为动画刷题。
- 36/72 小时的提醒/休养只作为研究原型的对照变量：比较“无时间提示”和“用户主动开启后的单次欢迎提示”，不作为 Beta 的业务状态机。

## 声音、动画与控制权

- Beta 默认静音，绝不自动播放。用户可自行选择“无声音、仅完成反馈、轻声陪伴”；学习页保持静音。
- 声音仅可在用户开启、应用前台、非答题状态且平台允许时按需尝试；失败即静默退化为文字，不反复申请权限。
- 首轮只使用静态场景和 2–4 秒、可停止的轻量动作。尊重系统和应用内的“减少动态效果”设置；不申请麦克风、相册、通讯录或精确位置权限。

## 商业化与研究边界

- 首轮 Beta 不真实收款、不投放广告。只用不可购买的概念卡验证房间/动作/声音、个性化学习计划和纯装饰内容的偏好。
- 永不售卖积分、学习完成记录、复习次数、基础互动、回归资格、关系恢复或排行榜优势；不使用抽卡、恐惧倒计时、默认续费或宠物受损来驱动付费。
- 研究同意独立、默认不勾选且不影响正常使用。仅最小化记录激活、学习与延迟复习、陪伴/压力反馈、声音偏好和概念卡偏好；不收集音频。
- 内部方向性信号包括：完成入组者中至少 60% 首周完成 3 次学习；至少 10 名自愿访谈者中半数陪伴感为 4/5 或以上；若超过 15% 参与者主动给出 4/5 或 5/5 的被提醒催促感，暂停扩展提醒/陪伴机制并先修正体验。

## 发布门槛

只有学习—积分闭环、数据与内容授权、自动化测试和研究门槛均通过，且生产依赖审计的 critical/high 为零时，才可邀请外部封闭 Beta 用户。当前已知阻塞项是生产依赖审计 `6 critical / 2 high`、H5 首屏约 301 KiB 超出建议阈值，以及本机 Taro H5 的 `system-configuration` 启动崩溃；未清除前仅允许内部演示和回归验证。
