# English Pet Care Plan

用英语学习建立习惯、获得治愈型虚拟宠物陪伴的应用。学习带来成长积分与宠物反馈；基础照料始终免费、可恢复，宠物不会因用户暂时离开而消失。

> 规则版本：v0.2.1（2026-08-23）
> 当前状态：首轮 Beta 的产品规则、状态机与研究口径已冻结；已完成陪伴状态机领域基线与欢迎/今日页前端基础。真实会话、数据库、API、学习积分事务和端到端闭环仍待实现。

## 技术基线

- 小程序前端：Taro + React + TypeScript；H5 仅用于浏览器回归验证。
- 服务端：FastAPI + Python，是积分、权益、宠物陪伴状态和后续排行榜的唯一规则权威。
- 数据：PostgreSQL + SQLAlchemy；M1 起引入 Redis 处理缓存、限流与幂等协调。
- 测试：Vitest + Testing Library（前端单元测试）、Pytest（服务端测试）、Playwright（H5 冒烟测试）；微信平台能力以开发者工具/真机补充验证。
- 架构和本地运行说明见 [docs/architecture.md](docs/architecture.md)。
- 多 Agent 的角色边界、任务卡和缺陷闭环见 [docs/agent-collaboration.md](docs/agent-collaboration.md)。
- 完整需求基线见 [docs/product-requirements.md](docs/product-requirements.md)，可点击的流程原型见 [docs/prototype/index.html](docs/prototype/index.html)。

## 核心循环

```text
背单词 → 获得积分与可信回执 → 解锁/记录陪伴反馈 → 看见英语与关系成长 → 继续学习
```

## 宠物与领养

- 首轮 Beta 每个账户领养 1 只可命名的默认猫咪（原型名为 Momo）；犬类、品种和多宠物仅在首轮验证通过后开放。
- 宠物会随真实时间在“正常陪伴、温和提醒、休养”间变化，但不会生病、死亡或失去既有关系。
- 领养时即开始 36 小时的安心期。此后，距最近一次服务端确认的基础互动或重逢超过 36 小时，显示可关闭的温和提醒；超过 72 小时进入安全的休养空间，暂停新的成长解锁。
- 在正常陪伴或温和提醒中，任意一项免费基础互动都会刷新最近互动时间；进入休养后，只有一次免费的“重逢”互动能恢复正常陪伴。学习不作为恢复资格。重逢不消耗积分、不要求购买、不产生额外收费。
- 宠物记忆会保留学习与互动里程碑；缺席不扣除既有亲密度或已解锁内容。

## 学习与积分

| 学习方式 | 首轮 Beta | 完成条件                | 单次积分 | 每日上限 |
| -------- | --------- | ----------------------- | -------: | -------: |
| 背单词   | 是        | 10 个词，正确率至少 80% |        8 |     3 次 |
| 英语阅读 | 否        | 完成文章阅读与理解题    |       20 |     2 次 |
| 口语练习 | 否        | 完成场景表达与复盘      |       35 |     2 次 |

- 首轮 Beta 只验证背单词是否能带来可持续的学习—陪伴闭环；阅读、口语的内容版权和评估方式另行评审。
- 积分不可为负；后续权益兑换失败时不扣除积分。
- 每日上限以用户入组时确认的 IANA 时区的本地日期计算，并由服务端裁决。首轮 Beta 不提供时区修改入口，避免通过修改时区追加当日额度。

## 基础照料与可恢复状态

所有状态判定由服务端按真实时间完成；客户端倒计时仅用于展示。

| 状态     | 触发条件               | 体验与下一步                                                 |
| -------- | ---------------------- | ------------------------------------------------------------ |
| 正常陪伴 | 已完成最近一次基础互动 | 宠物正常陪伴，并对学习给出反馈                               |
| 温和提醒 | 36 小时未互动          | 可关闭的轻提示；任选一次免费基础互动即可恢复                 |
| 休养     | 72 小时未互动          | 宠物在安全空间等待；只有免费重逢互动可恢复，不消耗积分或权益 |

- 喂食、补水和整理是免费的基础互动，不是强制资源消耗。
- 不存在虚拟疾病、药品、治疗倒计时、永久死亡、付费复活或救助道具。
- 提醒默认低频且可关闭；不使用责备、痛苦或恐惧文案推动用户回归。

## 幸福度与成长

- 成长由完成学习、温和互动和持续回归共同构成，展示为亲密度、共同记忆与可解锁场景。
- 缺席不会倒扣既有关系或已解锁内容；休养只暂停新的成长反馈。
- 成长、外观、互动动画和房间装饰为后续版本内容，不能提供额外学习积分、基础照料资格或排行榜优势。

## 成长、周报与商业化

- 个人周报、公开排行榜、犬类、多宠物、动态视频和付费内容均在 Beta 验证通过后再评审。若引入排行榜，照料次数、消费额、宠物数量和付费内容均不得参与排名。
- 后续仅考虑可选的外观、房间、互动动作、声音主题与个性化学习计划；不出售积分、学习完成记录、排名优势、基础照料资格、恢复休养资格或救助道具。
- 不使用抽卡/盲盒、强制广告、默认续费、隐藏价格或宠物受伤/离开来促成购买。

## 首轮 Beta 验证

- 招募 20–30 名年满 18 周岁的目标用户，进行 14 天封闭测试，不真实收款。完成入组指已成功创建会话、领养 Momo 并抵达今日页；研究同意独立、可跳过且不影响使用。
- 验证重点是首周完成至少三次学习、宠物陪伴感、提醒压力和对可选内容的付费意愿；不以在线时长、连续打开或焦虑点击作为成功指标。首周为 `enrolled_at` 起的 168 小时；D1/D7 分别记录入组后 24–48 小时、144–192 小时内是否有服务端确认的学习。
- 内部方向性信号：至少 60% 的完成入组用户首周完成三次学习；至少 10 名自愿访谈用户中一半对陪伴感给出 4/5 或以上；至少六名用户能说清愿意为哪类非数值内容付费及原因。
- 仅在 P0 闭环、数据/内容授权与测试门槛均通过，且生产依赖审计 critical/high 为零时，才可开始外部封闭 Beta；否则只允许内部演示和回归验证。
