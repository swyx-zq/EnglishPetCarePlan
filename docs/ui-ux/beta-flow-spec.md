# English Pet Care Plan — Beta UI/UX 流程规格

> 版本：v0.3
>
> 状态：与产品需求 v0.3 同步冻结
>
> 范围：单猫 Momo、可解释词汇学习、任选互动、默认静音与低压回归

## 1. 体验目标与边界

首轮 Beta 验证“短时英语学习能否形成可持续、没有负担的陪伴循环”。Momo 是学习结果的温和回应，不是需要用户按时维护的任务。

- 学习计划、题目、正确率、积分、额度、复习数量和记忆均以服务端回执为准；客户端只展示和提交。
- 用户离开、静音、关闭动效或跳过互动后，仍可学习、获得符合条件的积分、查看既有记忆和调整偏好。
- 喂食、补水、整理和打招呼为任选、免费互动，只表达陪伴，不改变学习资格、积分、关系数值、内容可见性或权益。
- 首次使用默认静音。声音、动效和实验性欢迎提示均可关闭；学习页不得播放环境声。
- Beta 不展示商城、购买、广告、狗狗、视频、阅读、口语、排行榜、36/72 小时倒计时、休养或重逢门槛。

## 2. Beta 信息架构

```text
今日 ─ 学习 ─ Momo ─ 我的
```

| 页面 | 用户要完成的事         | 主要内容                                                 | 主行动              |
| ---- | ---------------------- | -------------------------------------------------------- | ------------------- |
| 今日 | 知道现在可完成的下一步 | 服务端学习建议、今日额度、最近记忆、静态 Momo 场景       | 开始练习            |
| 学习 | 完成并理解一组词汇练习 | 10 题、即时作答反馈、结果、错词、语境、下次复习          | 继续作答 / 查看结果 |
| Momo | 感受和控制陪伴         | 猫咪档案、最近共同记忆、任选互动、静态/轻量反馈          | 打招呼（可选）      |
| 我的 | 管理学习与体验偏好     | 学习意图、词包偏好、账本、历史回执、声音/动效/提醒、隐私 | 保存偏好            |

研究反馈不属于主导航。它只可在学习结果、首次回归、Day 7/14 以可跳过卡片出现，不提供购买入口，也不以反馈换积分。

## 3. 核心流程

### 3.1 首次入组与领养

1. 欢迎页先说明“离开不会失去 Momo”“核心学习不受互动、声音或提醒影响”“声音默认关闭”。
2. 登录后，用户选择或跳过学习意图（日常沟通、旅行、职场基础、先体验）和熟悉度；跳过时提交通用起始词包选择。
3. 用户命名并领养 Momo。提交中不可重复提交；成功后显示真实领养时间和“从今天起一起学习”。
4. 今日页展示真实空状态：`0/3` 学习额度、无积分、无记忆。不得创建演示账户、68 分或历史记录。

### 3.2 词汇学习 → 可解释回执 → 陪伴记忆

```text
今日/学习页开始练习
→ 加载服务端签发的 10 题任务（含版本）
→ 逐题作答；答案只在服务端提交后确认
→ 结果页：正确数、错词、正确答案、简短语境、下次复习建议
→ 服务端确认积分/账本/可选记忆 → 今日刷新
```

- 开始前展示服务端给出的预计时长、剩余额度和词包/复习提示；未开放内容只说明“暂未开放”，没有可执行入口。
- 达到 `8/10` 时显示“本组完成，获得 8 分”；低于阈值时显示“这组已记为练习，先看看错词后再试一次”，不得出现“失败”、宠物失望或关系变化。
- 每个错词显示正确答案和一条短语境/搭配；结果同时显示服务端给出的下次复习建议。
- 所有提交覆盖 `submitting`、`confirmed`、`previous_result_available`、`retryable_error` 四种状态。网络恢复或重复点击不得导致重复积分、重复记忆或重复动画。
- 一天内最多一次明显完成反馈动画；其余确认结果仅轻量更新，不鼓励刷题。

### 3.3 可选互动与欢迎回来

- Momo 页可以展示喂食、补水、整理、打招呼等任选互动。每项必须标记“免费、不会影响学习或积分”。
- 用户长期未打开时，今日页可显示“欢迎回来”和最近一条共同记忆，主行动仍是“开始练习”。不显示离开时长、倒计时、恢复资格、休养或重逢。
- 如用户主动加入欢迎提示实验，最多显示一次低频、可关闭的提示；关闭后不改变任何服务端业务事实。

### 3.4 声音、动效与媒体降级

| 偏好           | 可播放时机                               | 不可播放时机                       | 失败退化        |
| -------------- | ---------------------------------------- | ---------------------------------- | --------------- |
| 无声音（默认） | 从不播放                                 | 所有页面                           | 纯文字/静态场景 |
| 仅完成反馈     | 已确认学习结果后，用户仍在前台且平台允许 | 作答、提交中、后台、页面恢复       | 文字成功状态    |
| 轻声陪伴       | 今日/Momo 前台且非答题状态，平台允许     | 学习页、后台、恢复前台、未开启偏好 | 文字/静态场景   |

- 使用 2–4 秒、可停止的轻量反馈；减少动效时不播放非必要动画。
- 首屏只加载静态 Momo 场景和必要 UI。音频按需加载，禁止 `preload="auto"`；音频、图片或未来视频失败时不影响学习/账本/记忆。
- 不申请麦克风权限；不因媒体失败反复请求交互或权限。

## 4. 统一页面状态

| 状态            | 展示                            | 可用行动              |
| --------------- | ------------------------------- | --------------------- |
| 未登录/会话失效 | 只读规则与“登录后保存记录”      | 登录/重新授权         |
| 无宠物          | 空状态与领养说明                | 命名并领养            |
| 无可用任务      | 服务端原因（额度、内容或网络）  | 查看上次结果/稍后重试 |
| 任务加载/提交中 | `aria-busy`、不可重复提交       | 等待/取消安全返回     |
| 学习未达阈值    | 错词、语境、再次练习建议        | 查看错词/稍后重试     |
| 学习已确认      | 结果、账本、下次复习、可选记忆  | 返回今日              |
| 网络/服务错误   | 可理解文本和关联 ID（如可提供） | 重试/查询上次结果     |
| 媒体不可用      | 静态 Momo 与文字反馈            | 关闭声音/继续学习     |

## 5. 无障碍与语义

- 页面具备 `main`、唯一 `h1`、清晰导航和键盘焦点；颜色不是唯一状态传递方式。
- 学习进度使用带名称的 `role="progressbar"`，例如“本组学习进度，第 4 题，共 10 题”。
- 用户主动提交的结果使用 `role="status"` 或 `aria-live="polite"`；自然场景文案和媒体状态不得反复打断读屏。
- 声音、动效和欢迎提示开关均有可访问名称、当前状态和解释文字；尊重 `prefers-reduced-motion`。
- 错词纠错必须可读、可聚焦并与题目关联；结果页无需重新答题即可阅读已确认结果。

## 6. 推荐语义选择器

```ts
getByRole('navigation', { name: '主导航' })
getByRole('button', { name: '开始练习' })
getByRole('progressbar', { name: '本组学习进度' })
getByRole('status', { name: '学习结果' })
getByRole('button', { name: '保存声音偏好' })
getByText('离开不会失去 Momo', { exact: true })
```

仅在没有稳定语义定位时使用以下测试标识：

```text
authoritative-learning-receipt
study-result-review-list
welcome-adoption-action
media-preference-control
research-feedback-card
```

## 7. 前端验收清单

- [ ] 新用户可完成安心说明、登录、目标选择/跳过、命名和领养；不会看到伪造积分或历史。
- [ ] 服务端签发 10 题、服务端确认答案、错词/语境/下次复习与积分回执完整呈现；前端不计算业务结果。
- [ ] 低于 80%、额度耗尽、任务失效、重复提交、会话失效、离线和超时均有可读界面与安全重试。
- [ ] Momo 互动、静音、减少动效、长期离开都不限制核心学习；没有倒计时、休养、重逢或关系惩罚。
- [ ] 首次默认静音，页面切换、提交答案和恢复前台均不自动播放；媒体失败可完整退化。
- [ ] 键盘与读屏可完成导航、学习、查看错词、调整偏好和关闭研究提示。
- [ ] Playwright 覆盖登录/领养、学习成功/未达阈值、重复提交、网络失败、欢迎回来、静音和减少动效。
