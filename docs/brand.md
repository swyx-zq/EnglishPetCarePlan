# 品牌与视觉基线

> 版本：v0.1
> 状态：产品名称和视觉方向已确定；正式域名与各平台发布资料待确认。

## 产品名称

| 用途 | 名称 |
| --- | --- |
| 中文正式名称 | 英语养宠计划 |
| 英文正式名称 | English Pet Care Plan |
| 代码标识 | `english-pet-care-plan` |
| 首屏短句 | 学一点英语，照顾好一个生命。 |

中文名称用于微信小程序标题、通知和中文内容；英文名称用于代码、OpenAPI 标题、海外素材和技术文档。两个名称必须同时出现于商店资料、隐私政策和官网页脚，避免用户误认产品主体。

## 图标

图标由“宠物面孔”和“打开的学习书本”组成：

- 宠物面孔传达陪伴与照料，不用单一物种，保持猫狗均可代入。
- 打开的书本传达英语学习是核心行为，而不是附属装饰。
- 采用圆角正方形和低饱和暖色，适配小尺寸图标；不使用文字、渐变和过细线条作为关键信息。

源文件为 [brand-mark.svg](../apps/mini/src/assets/brand-mark.svg)。小程序发布时，需由项目负责人将经确认的 PNG 导出件上传至微信公众平台；仓库 SVG 不是已发布的商店图标。

## 视觉方向

**关键词**：温暖、清醒、陪伴、可解释。

界面采用浅杏色背景、深棕文字、橙色学习行动与绿色稳定状态。警告、疾病和死亡等严重状态必须配合清晰文案、图标和可操作下一步，不能只依靠颜色或卖萌表达。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `ink` | `#292524` | 主文字与高对比边界 |
| `surface` | `#FFF7ED` | 页面背景 |
| `surface-raised` | `#FFFFFF` | 卡片与浮层 |
| `learning` | `#C2410C` | 学习任务和主行动 |
| `care` | `#257953` | 正常照料与成功状态 |
| `warning` | `#B45309` | 需要关注但可恢复的状态 |
| `danger` | `#B42318` | 不可逆或高风险状态 |

字体现阶段使用系统字体，避免在首屏加载额外字体文件。圆角、间距、阴影和颜色均从 `apps/mini/src/styles/tokens.scss` 取值，页面不得自行硬编码新的品牌色。

## 域名与发布资料

正式域名尚未确认。确认前不得在界面、邮件、二维码或用户协议中展示未验证的域名；选择时至少完成：

1. 域名可注册性和续费成本核验。
2. 目标市场的商标/名称冲突初筛。
3. 与微信小程序主体、隐私政策和服务端 API 域名的归属一致性确认。

域名购买、微信平台图标上传和主体信息填写属于外部不可逆操作，需项目负责人明确授权后执行。
